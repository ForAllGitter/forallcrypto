# ForAllCrypto

Website for [ForAllCrypto](https://forallcrypto.nl) — crypto payments for shops, webshops and service businesses. Dutch-first, English toggle. CoinGate is the recommended route.

## Import on Netlify

1. Open [Import from Git](https://app.netlify.com/start) and choose **GitHub**.
2. Select **ForAllGitter/forallcrypto**.
3. Leave the settings as they are (`publish` = `.`, no real build).
4. Deploy.

Or use the one-click button:

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/ForAllGitter/forallcrypto)

Branch: `main`.
